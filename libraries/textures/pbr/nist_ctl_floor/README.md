# NIST/CTL Floor PBR Pack

Procedural NIST/CTL presentation texture pack. The pack adds a subtle floor
badge with NIST, CTL, and ORCHAV text while keeping the base material neutral
enough for propagation and visualization examples.

The checked-in PNG files are the reviewed texture assets used by ORCHAV. They
use text and geometric inlays rather than downloaded logo files. Use the
bundled files directly because recreating text-based maps with other system
fonts can change their appearance.
