# Illustrative water ripples

Original ORCHAV procedural artwork, generated by `generate_maps.py`; no external
images or data were used. Distributed under ORCHAV's repository license.

Three 2048 × 2048 maps repeat over a 256 m tile: restrained blue-green albedo,
tangent-space normals derived from fifteen periodic wave components, and
roughness. Broad surface variation remains visible from a city overview while
short ripples add detail nearby. The albedo varies only slightly; most detail
comes from the normal and roughness response to scene lighting.

The default uses dielectric reflectance for an illustrative water index of
refraction of 1.333, normal strength 0.8 and roughness 0.45 multiplied by the
roughness map. It remains opaque. These are generic appearance settings, not
measured water properties or a reconstruction of local waves, currents or depth.
The mesh remains flat: no hydrodynamics, motion, displacement or radio-scattering
change is implied.

The OSM water visual default uses these maps when textures are enabled. Disabling
textures keeps the plain water color. Other scenes and authored/manual appearance
choices retain their existing policies. Regenerate from the repository root:

```bash
python libraries/textures/pbr/water_ripples/generate_maps.py
```
