# Dimensioned UAV targets

These two rigid quadrotors use dimensions from 3GPP examples. Both are original ORCHAV meshes generated by [build_meshes.py](build_meshes.py) and distributed under the [repository license](../../../LICENSE).

| Mesh | Full dimensions (forward × left × up) | Reference |
| --- | --- | --- |
| [compact](compact/geometry.json) | 0.3 m × 0.4 m × 0.2 m | TR 38.765 V20.0.0, Annex A, small UAV example |
| [large](large/geometry.json) | 1.6 m × 1.5 m × 0.7 m | TS 22.137 V19.1.0, UAV example |

Each mesh uses metres and scenario scale 1.0. The origin is the centre of the bounding box, including blades and landing gear. Each folder includes a `drone.obj` mesh and a `geometry.json` file with its bounds, component groups, and rotor geometry.

Use these targets for geometry studies. Their dimensions alone do not establish a calibrated radar cross section, and the fixed blades produce no rotor micro-Doppler. See [sensing result interpretation](../../../docs/sensing/concepts.md).

To regenerate both meshes, run this command from the repository root.

```bash
python libraries/targets/uav/build_meshes.py
```
