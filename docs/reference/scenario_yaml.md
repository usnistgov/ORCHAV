# Scenario YAML Reference

Use this page to look up `scenario.yaml` fields, accepted values, defaults, and
constraints. If you are creating your first scenario, start with
[Scenario Authoring](../generator/scenario_authoring.md). The compact example below
shows how the common fields fit together.

<!-- BEGIN EXAMPLE: minimal-scenario -->
```yaml
schema_version: 2

scene:
  source: sionna
  id: etoile

timeline:
  steps: 1
  duration_s: 0.0

actors:
  tx:
    - name: TX1
      mobility:
        type: stationary
        position_m: [-114.0, 37.0, 30.0]
  rx:
    - name: RX1
      mobility:
        type: stationary
        position_m: [-27.18, -12.61, 1.5]

raytracing:
  enabled: true
```
<!-- END EXAMPLE: minimal-scenario -->

## Scenario Schema Version

Every `scenario.yaml` requires `schema_version: 2`. It identifies the YAML
format accepted by ORCHAV `0.1.0`. A missing or unsupported value fails
validation before generation or visualization. Keep it at `2` rather than
incrementing it when you edit a scenario.

[Versions and Compatibility](compatibility.md#scenario-yaml) maps this authored
value to the separate frame, HDF5, coverage, and gRPC identifiers and explains
what to do when a version is rejected.

schema value, so the consuming component may choose a runtime default. Common

when the documented behavior already provides the intended result, and run
`orchav-validate` on the complete scenario before generation.

## Common Scenario Fields

These fields identify the schema, select the scene, define the shared timeline, and control root-level logging or component settings. The root `visualizer` mapping is component-owned. See [Visualizer Scenario Defaults](../visualizer/scenario_defaults.md) for supported subkeys.

### Scenario document

Root-level format, logging, and component-extension fields.

| YAML key | Type / values | Default / requirement | Meaning |
|---|---|---:|---|
| `schema_version` | integer; `2` | required | Required format identifier for `scenario.yaml`. ORCHAV 0.1 accepts only `2`. |
| `timeline` | mapping | required | Shared endpoint-inclusive scenario timeline. |
| `actors` | mapping | empty role lists | Optional YAML-authored transmitter, receiver, and target actors. |
| `groups` | sequence of mapping | `[]` | Optional shared mobility groups referenced by actors. |
| `scene` | mapping \| null | not set | Scene selection block. |
| `data` | mapping | `files` mode with standard `frames/` settings | Frame data mode block. |
| `raytracing` | mapping \| null | not set | Generator ray-tracing settings. |
| `coverage` | mapping \| null | not set | Optional coverage-map computation settings. |
| `view_defaults` | mapping \| null | not set | Visualizer view defaults. |
