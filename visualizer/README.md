# Visualizer source

The Visualizer displays the scene, actor trajectories, and propagation paths
from a scenario. To open a recording and inspect a path, follow
[Your First Visualizer Session](../docs/visualizer/first_session.md).

For a local sensing recording, the [Sensing Dashboard](../docs/visualizer/sensing_dashboard.md)
lets you inspect range and velocity, see which returns became detections, and
follow tracks alongside the scene.

| Folder | Purpose |
| --- | --- |
| `src/` | Application code, including scene loading, renderers, playback controls, analysis panels, and notebook support. |
| `resources/` | UI assets and [editable ORCHAV logos and icons](resources/branding/README.md). |

The [Visualizer guide](../docs/visualizer/README.md) covers analysis tasks and rendering options. The [Visualizer scenarios](../scenarios/visualizer/README.md) provide recordings or instructions for generating them.
